ToneCheck v1.6 🏆
ToneCheck 是一款专为游戏本地化 (Game LQA) 和精细化翻译设计的语气校验工具。通过 AI 模拟特定人设，实时评估译文是否符合角色性格。

ToneCheck is an AI-powered tone consistency checker designed specifically for game localization and LQA. It evaluates whether a translation aligns with a specific character persona in real-time.

🌟 核心功能 | Key Features
五级评价体系 (5-Tier Grading):

🏆 信达雅 (Tier S): 神级本地化，捕捉灵魂 | God-tier localization.

✨ 注入灵魂 (Tier A): 人设准确，表达地道 | Excellent character voice.

🤔 差点意思 (Tier B): 意思正确，语气平淡 | Accurate but generic tone.

🤡 OOC警告 (Tier C): 语气违和，严重出戏 | Out-of-character mismatch.

💀 致命错误 (Tier D): 错译漏译，意思偏差 | Mistranslations or critical errors.

人设管理 (Persona Manager): 预设人设（暴躁矮人、高贵精灵等），并支持自定义保存个人常用人设。

多模型支持 (Multi-Provider): 支持 DeepSeek、OpenAI 及自定义 API 接入，灵活适配不同大模型。

历史回溯 (History System): 自动保存最近 50 条检查记录，支持一键加载复盘。

双语界面 (Bilingual UI): 全界面中英对照，适配国际化工作环境。

📖 如何使用 | Usage
设置 API Key: 点击右上角设置图标，填入你的 API Key。

输入文本: 左侧分别输入原文和你的译文。

选择人设: 在下拉菜单选择或自定义目标角色的人设描述。

开始检查: 点击 "Start Check"，获取深度 LQA 反馈。
